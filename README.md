# Radiohead

UE5 ARPG DEMO



可玩版 V0.2

进游戏请先按G/RT切换武器。



\### 玩法说明：

攻击获得红色能量。左上角第三条显示。默认存储三格。装填可以把小格融合为外框的共鸣槽。（理解为开刃就行）

装填格子数越多共鸣槽颜色越深，等级越高，衰减时间越长。

闪避成功可以增加共鸣时长。

（双刀特殊情况：攻击获得共鸣槽，装填将共鸣槽反向兑现为格子）

弹反可以获得蓝色能量。

红+红+蓝=红3级，哪个颜色最多装填的就是哪个颜色。

红+蓝装填=黄。

消耗能量命中敌人可以增加敌人破防条，并增加我方终结技充能。



\### 键位（默认手柄）：

LT 装填（需要左上角第三条不为空）

RT 切换武器

RT长按 终结技（左上角黄条充满时可使用）

RB 普攻

B 闪避

Y X 战技1 战技 2

A 法术（远程）

十字键下键 法术2（回血）

LB 防御/弹反/当身闪避（随武器变化）

9 生成敌人

0 回到测试区域

B 长按奔跑

RS 锁定

LS 跳跃



\### 如何使用战技和法术：

共鸣槽会被消耗，算作一格。

法术1：远程射击，需要四格能量。即3格+1共鸣槽

法术2：回血，20血。需要三格能量。

长刀战技1：四格能量。红蓝颜色数量相等时，威力最强。比如蓝红蓝格子+红色共鸣槽

长刀战技2：四格能量。

大剑战技1：四格

大剑战技2：忘了，三格还是四格

双刀战技1：四格，必须红蓝颜色数量相等

双刀战技2：两格起手，可以再花费1+1格派生后续的两段连招。连招窗口小，记得多按。

放不出来怎么办：让红蓝颜色数量相等



\### 大剑特殊效果：

大剑防御被命中会积攒灰色能量，灰色能力攒满后再被攻击就破防。（总之就是连续防御第四下破防）

大剑可以和敌人相杀，获得三级蓝色共鸣，并把灰色能量转换为蓝色能量。

双刀当身和见切一样，消耗共鸣才能有效果。当身成功可以将红色共鸣转换为3格蓝色。
